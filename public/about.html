Chibi.gg é um companion TFT-first voltado a perfil, histórico e revisão pós-partida. O objetivo é transformar dados disponíveis em evidências que o jogador possa revisar sem remover decisões do jogo.

Demonstração para avaliação

Se a Riot API temporária estiver indisponível durante a revisão, use o modo sintético. Ele carrega um perfil fictício com 12 partidas e permite navegar por histórico, Coach, Ask Chibi e detalhes de partida sem fazer chamadas à Riot.

Abrir a demonstração sintética →

Perfil e histórico

O protótipo demonstra o fluxo por Riot ID. Consultas à Riot passam por funções de backend; chaves de API não ficam no bundle público.

Review pós-partida

As análises usam principalmente o snapshot final retornado pela Match API e apontam para as partidas/amostras usadas.

Chibi Dataset

Estatísticas agregadas vêm de partidas observadas pelo produto. Amostra e confiança são exibidas e o dataset não é apresentado como toda a população de TFT.

RSO na produção

O protótipo usa lookup para permitir avaliação. Após aprovação da aplicação de produção, o fluxo pessoal está preparado para migrar para Riot Sign On conforme as instruções da Riot.

Fontes atuais

  • account-v1 para resolver Riot ID.
  • tft-summoner-v1 e tft-league-v1 para perfil/rank.
  • tft-match-v1 para histórico e detalhes pós-partida.
  • tft-status-v1 para status do serviço.
  • Data Dragon/TFT static data para assets e dados estáticos.

Limites de gameplay

Chibi.gg não oferece opponent scouting em tempo real, não rastreia boards adversários para decidir a próxima jogada, não prevê ações de oponentes e não automatiza compra, venda, reroll, level up ou posicionamento. O produto também não cria MMR/ELO alternativo.

O Companion público é uma demonstração de revisão. Captura live não está habilitada na versão pública atual. Qualquer integração futura depende das aprovações aplicáveis e deve continuar review-first.
